# Мои файлы — личный Android-файловый менеджер

Личное приложение для одного владельца (vivo X300 Pro, Android 16), не для Google Play.

- Требования: `PROJECT_SPEC.md` · статус и следующий шаг: `PROJECT_STATUS.md` · история: `CHANGELOG.md`
- Утверждённый макет: `design/reference.png`
- Подпись и обновления: `docs/SIGNING.md`

## Возможности

- Главная по макету: память устройства, настраиваемые плитки разделов и нижняя панель (до 5 вкладок).
- Файлы: обзор папок, «Новые», категории, поиск, копирование/перемещение/переименование, корзина с восстановлением.
- Просмотр: фото (масштаб, перелистывание), видео (Media3, ±10 с двойным касанием), текст, PDF.
- Архивы: ZIP/ZIPX, 7z, RAR (до v4, только чтение), TAR и TAR.GZ/XZ/ZST/BZ2, GZ/XZ/ZST/BZ2; создание ZIP и 7z.
- Приложения: список, запуск, экспорт APK и split-наборов (.apks), установка через системный установщик.
- Заметки, ссылки, избранное; резервные копии (ручные и автоматические, по желанию с паролем).

Сеть используется для значков сайтов в «Ссылках» (выключаются в меню) и явно включаемой
локальной передачи HTTPS. Передача не использует облако, регистрацию или внешний сервер.
Описание протокола, состояния проверки и ограничений: [docs/TRANSFER.md](docs/TRANSFER.md).

## Сборка

Сборка и тесты выполняются в GitHub Actions (`.github/workflows/android.yml`):

- `./gradlew testDebugUnitTest assembleDebug` — модульные тесты и debug APK (arm64 и universal);
- коммит с `[apk]` в сообщении публикует приватный пререлиз с APK и SHA-256;
- задание `device-tests` проверяет приложение на эмуляторе Android и публикует скриншоты в ветку `ci-device-shots`;
- release-APK подписывается, если в секретах репозитория есть ключ владельца (см. `docs/SIGNING.md`).

Локально: Android SDK, JDK 21, `./gradlew assembleDebug`.
