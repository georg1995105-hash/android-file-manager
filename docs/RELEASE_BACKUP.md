# Резервная копия RELEASE-подписи

Файл: [android-file-manager-RELEASE-key-d282ae0bb49c-backup.tar.age](https://drive.google.com/file/d/1PrbzqsF_PPa7JeJWd5XsO5-ivS3f4of2/view).
SHA-256 зашифрованного архива: `a87d46387dd57997212c71272b671b0ada4b3b645a089ac0ac9b622e5ea1590f`.
Сертификат RELEASE: `d282ae0bb49c30bd848fcae3ae02533ff446a12ef7e3691863af53c4aa0ecda7`.
Копия скачана обратно из закрытого Drive и побайтово сверена. Закрытый SSH-ключ расшифрования остаётся у владельца.

Резервная копия содержит исходный release-keystore, alias, пароли, публичный сертификат и контрольные
суммы. Все эти данные находятся внутри архива, зашифрованного утилитой age на публичный ключ владельца.
Закрытый ключ расшифрования хранится только у владельца, отдельно от GitHub Secrets и резервного архива.

Не отправляйте закрытый ключ, расшифрованный архив, keystore или пароли в чат, Git и обычные CI-артефакты.
В Google Drive допускается только зашифрованный файл `.tar.age`; доступ к нему не следует делать публичным.

## Восстановление владельцем

На своём защищённом ПК/сервере с установленной утилитой age:

```sh
umask 077
mkdir pfm-signing-restore
age --decrypt --identity /path/to/owner-identity --output pfm-signing-restore/backup.tar release-signing-backup.tar.age
tar -xf pfm-signing-restore/backup.tar -C pfm-signing-restore
```

Проверьте контрольные суммы из `SHA256SUMS` и отпечаток сертификата из `identity.json`. Исходный ключ
нельзя заменять новым: подпись установленного приложения должна сохраняться во всех последующих версиях.
Файл `secrets.json` содержит значения для защищённого восстановления GitHub Secrets; не выводите его в терминал.

После восстановления держите keystore и пароли в защищённом хранилище владельца. Зашифрованный архив
и ключ его расшифрования должны иметь независимые резервные копии.

Проверка RELEASE → RELEASE выполняется только на чистом эмуляторе и не изменяет установленное у владельца
DEBUG-приложение. APK с новой RELEASE-подписью нельзя установить поверх DEBUG APK с другой подписью.
