# Локальная передача 0.10.0

## Реализация

Раздел «Передача» и действие «Передать» в контекстном меню/меню множественного выбора.
Выбор файлов готовит явный список доступных файлов; список можно отозвать. Автоматического
доступа ко всему хранилищу по сети нет. Папки обходятся без симлинков, до 1000 файлов за выбор.

Один ограниченный HTTPS API обслуживает встроенный Android/TV клиент и локальную веб-страницу.
ПК нужен только браузер. Встроенный сервер включается пользователем и работает в foreground service
с уведомлением и кнопкой остановки. Интернет и облако для передачи не используются.
NSD `_pfmtransfer._tcp.` объявляет и обнаруживает устройства. Адрес и код доступны для ручного ввода;
QR открывает браузерную страницу и подставляет код. Приложение не требует камеры.

Первое подключение: сверить SHA-256 локального TLS-сертификата → ввести краткоживущий код → подтвердить
подключение на получателе. Android-клиент может запомнить сертификат; изменение сертификата требует
повторной сверки. Это отдельный ключ транспорта в Android Keystore, не ключ подписи APK.
В браузере необходимо принять локальный сертификат после сверки; автоматизация тестового браузера
доверяет только тестовой среде и не проверяет пользовательский диалог сертификата.
Каждый входящий файл отдельно подтверждается получателем. Сеанс действует час, код — две минуты.

Потоковая отправка/приём: 64 КиБ буфер ядра, блоки до 4 МиБ (клиенты используют 1 МиБ), SHA-256 блока
и всего файла, смещение Long, проверка длины. Подтверждение блока выдаётся после синхронизации записи.
При обрыве браузер может продолжить текущий файл без перезагрузки страницы; Android отправитель
повторяет блок с проверкой подтверждённого смещения. После гибели процесса требуется новое подключение.
Отмена/остановка удаляет незавершённые данные. Android-получение при обрыве начинается заново.

Файлы публикуются в приватном `files/received/<batch>/...` после проверки. «Полученные файлы» открывает
обычный обозреватель приложения, где доступны существующие просмотр/копирование/установка APK.
Пути относительные, с ограничением глубины; обход родительских каталогов, управляющие символы и
зарезервированные имена отклоняются. Повторный путь в группе отклоняется без перезаписи.
APK не устанавливаются автоматически. Папки отправляются как набор файлов с относительными путями.

## Границы защиты

TLS 1.2 шифрует трафик. До ручной сверки сертификата первое подключение уязвимо к подмене в локальной
сети. Пиннинг Android-клиента сравнивает точный сертификат, а не только имя/IP. Доверие к сертификату
не заменяет подтверждения операций. Предъявляемое имя участника не доказывает его личность.

Сервер принимает только локальные адреса клиентов, имеет ограниченные заголовки, тело запроса,
пул работников, очередь и таймаут чтения. Не поддерживает chunked requests, дубли заголовков,
проксирование или произвольные пути. Numeric Host + проверка Origin ограничивают DNS rebinding/CSRF.
Браузерные ресурсы встроены, без внешних библиотек/CDN. Bearer-токены живут в памяти и не попадают в QR.
Браузерная ссылка скачивания содержит временный непредсказуемый билет, действует до остановки/истечения
сеанса/отзыва списка. Закрывайте сеанс после работы; передавать такую ссылку другим не следует.

## Проверки

- Компиляция приложения и инструментальных тестов прошла локально до последних интеграционных правок;
  окончательный результат фиксируется в отчёте CI.
- Автономные JVM-проверки: приём/обрывы/повреждения/смещения/имена/отмена/дубликаты, 26 проверок;
  дополнительно проверены строгий HTTP framing, Origin, Host и ограничение тела.
- JavaScript SHA-256 сверяется с Node crypto на девяти длинах, включая границы блока/padding.
- Chromium со стендовым HTTPS-сервером: отправка 2 МиБ + 23 байта, искусственный обрыв,
  продолжение, публикация после SHA-256, скачивание и побайтовая сверка — PASS.
  Сопряжение на этом стенде подменено фикстурой; Android pairing проверяется отдельным тестом.
- Phone/TV: `TransferIntegrationTest` проверяет настоящий Android TLS, pinning, аутентификацию,
  подтверждение и оба направления; `TransferUiTest` — запуск раздела и кнопки через D-pad Center.
  PASS на эмуляторах phone API 35 и TV API 30: CI #40717168837 (2026-10-28).
- Ключ TLS в Android Keystore (`local-transfer-tls-v2`) разрешён для `DIGEST_NONE`, PKCS1/PSS и расшифровки:
  этого требует TLS-сервер Conscrypt. Без этого рукопожатие обрывается.

## Оставшиеся ограничения

- Обнаружение/ручной клиент ориентированы на IPv4. Гостевые сети, изоляция клиентов и блокировка mDNS
  могут мешать; ручной адрес помогает только если устройства маршрутизируются друг к другу.
- Пустые папки не передаются. При скачивании папок браузером файлы скачиваются отдельно, имя пути
  преобразуется в имя файла; автоматического восстановления дерева на ПК нет.
- Браузерное скачивание ведёт сам браузер; полная SHA-256 показана для независимой проверки.
- Нет обещания возобновления после перезапуска приложения, перезагрузки страницы или изменения источника.
- Получение в Android хранит данные в приватной памяти приложения; для постоянного хранения вне приложения
  скопируйте их обычными средствами менеджера. Удаление приложения удалит приватные полученные файлы.
- targetSdk 36 сохранён. При повышении targetSdk потребуется учесть runtime local-network permission.
- Полное управление всеми прежними экранами приложения пультом, физические устройства, Safari/Firefox,
  Windows/macOS и многочасовые передачи ещё требуют отдельной проверки. Не заявлены как проверенные.
