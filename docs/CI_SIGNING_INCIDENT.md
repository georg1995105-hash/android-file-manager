## Первопричина

Рабочие опубликованные APK были подписаны ключом из кэша `pfm-debug-keystore-v1` ветки
`ccr-01aed2a6-se8umi`. В `main` этот кэш недоступен по правилам области видимости Actions.
Во всех трёх заданиях #40305412451 зафиксирован cache miss. Gradle использовал стандартную debug-подпись:
при отсутствии keystore он создаёт новый ключ на каждом изолированном раннере.
В конце запуска планшет записал свой новый ключ в кэш main; задание build не смогло сохранить свой
(`Unable to reserve cache ... another job may be creating this cache`). Следовательно, простой повтор
упавшего задания использовал бы уже другую историю ключей и не восстанавливал исходную подпись.

Телефон сначала успешно установил опубликованный 0.8.0. Новый тестовый APK установился, но Android
отказал в запуске instrumentation на старом приложении из-за другой подписи. До проверки миграции
заметки выполнение не дошло. Последующая установка нового приложения поверх также была отвергнута.
Планшет не проверял обновление со старого APK: совместимость новой пары app/test в одном задании
не доказывает совместимость с опубликованной версией. Признаков проблемы состояния эмулятора нет.

## Корректное исправление

- Не менять applicationId, versionCode, исходную подпись или данные приложения.
- До сборки проверять сертификат сохранённого ключа; не создавать замену при cache miss.
- До любых действий с эмулятором печатать и сверять сертификаты всех трёх APK. Ошибка подписи должна
  останавливать сценарий, сохраняя диагностические данные.
- Сохранить проверку «старый APK → заметка → install -r → заметка на месте». Отсутствие предыдущего
  релиза является ошибкой, а не успешной или пропущенной проверкой на телефоне.
- Для стабильной сборки в main нужен именно исходный закрытый ключ в доступном защищённом хранилище.
  Если нет ни исходного кэша, ни резервной копии, закрытый ключ нельзя восстановить из сертификата или APK.
  Тогда бесшовное обновление установленного приложения подтвердить или обеспечить невозможно;
  корректно блокировать несовместимый выпуск, сохраняя установленное приложение и данные.
