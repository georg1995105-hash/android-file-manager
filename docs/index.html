Файлы на всех ваших устройствах

Передача — файловый менеджер для Android, планшетов и Android TV. Открывайте фотографии, видео и документы, передавайте файлы напрямую по Wi-Fi или используйте личный Google Диск для передачи между устройствами, которые не включены одновременно.

Передача по Wi-Fi

Подключите устройства к одной локальной сети и отсканируйте QR-код. Аккаунт не требуется.

Личное облако

Дополнительная функция использует Google Drive API с разрешением drive.file. Подключите один и тот же собственный аккаунт на своих устройствах. Файлы, отправленные через приложение, доступны на другом устройстве после входа в этот аккаунт. Облачная функция проходит проверку; доступность зависит от версии приложения и статуса авторизации Google.

Управление файлами

Локальный просмотр, поиск, файловые операции, сохранённые ссылки, резервные копии и обновления приложения.
