- **Что сделано в 0.8.0:**
  1. Просмотр фото/видео — кнопка «В корзину» в нижней панели с подтверждением; файл убирается из просмотра только
     после успешного перемещения в корзину приложения.
  2. Панели просмотра скрываются через 3 с без касаний (вместе с системными), одно касание возвращает; не скрываются,
     пока открыто меню/диалог или палец на ползунке.
  3. Фото и видео одного списка в одном просмотре, переход к соседнему файлу свайпом; жесты сохранены (щипок и двойное
     касание у фото, двойное касание ±10 с и ползунок у видео); один плеер, видео грузится после остановки свайпа;
     кнопки панели — порядок и видимость («Ещё → Настроить кнопки…», есть «Предыдущий/Следующий файл»).
  4. «Ссылки» — значок сайта слева: HTTPS, только с сайта самой ссылки, кэш в памяти и на диске (30 дней, после
     неудачи — сутки), стандартный значок при недоступности, выключается в меню. Добавлено разрешение INTERNET —
     только для этой функции.
  5. Долгое нажатие на файл включает выбор (список, сетка фото/видео, «Недавние»), касания добавляют файлы, панель
     с количеством и действиями, «Назад» снимает выбор. Удержание плиток, карточки памяти, приложений, заметок,
     ссылок, избранного больше ничего не открывает (раньше clickable срабатывал после удержания).
  6. «Иконки разделов → Плиток в ряду»: Авто, 2–6; авто — 3 на телефоне вертикально, 5 горизонтально, на планшете
     больше; названия плиток в одну строку с уменьшением шрифта.
  7. Ориентация: просмотр открывается в текущей ориентации устройства (раньше принудительно портретная), без датчика;
     кнопка поворота меняет явно; при выходе ориентация сохраняется. На Android 16 с большим экраном кнопка скрыта
     (система игнорирует запросы ориентации).
  8. Производительность (найденные причины): миниатюры из системного кэша MediaStore вместо декодирования исходников
     при прокрутке; списки без подкомпозиции Coil; главная при каждом возврате не загружает подписи всех приложений
     (кэш 2 мин) и не читает все заметки (COUNT); поиск субтитров вне UI-потока; ползунок видео опрашивается только
     когда виден. Попутно: итог файловых операций публикуется в главном потоке (Toast из фонового потока падал).
