# История изменений

## 0.1.0 (versionCode 1) — в работе, ЭТАП 1

- Каркас проекта: Kotlin + Jetpack Compose (Material 3), AGP 9.4.1, Gradle 9.8.2, minSdk 30, targetSdk 36.
- Главная «Мои файлы» по утверждённому макету: реальная память устройства, плитки разделов, недавние файлы.
- Настройка плиток (порядок, видимость, значок, цвет) и нижней панели (до 5 вкладок) с сохранением в DataStore.
- Обзор папок, создание папки, сортировки, скрытые файлы; «Новые» по дате добавления; категории из MediaStore.
- Поиск по именам, сведения о файле, системное «Поделиться» (FileProvider), встроенный просмотр фото и текста.
- Отступления от макета по ТЗ: нет раздела «На ТВ» и вкладки «Облако».
